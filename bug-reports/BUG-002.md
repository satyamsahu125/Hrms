# Title

Terminated employee can still log in to the system

## Severity
High

## Priority
High

## Description

After an employee account is marked as terminated/inactive by HR, the employee is still able to log in to the application using existing credentials.

## Steps to Reproduce

1. Launch the application.
2. Login as HR/Admin.
3. Click on Employees from the left navigation bar.
4. Select an active employee and click on Edit icon under actions.
5. Change employee status to Terminated/Inactive.
6. Save the changes.
7. Logout from Admin account.
8. Login using the terminated employee credentials.
9. Observe that Terminated/Inactive user can login into the system.

## Expected Result

A terminated or inactive employee should be blocked from log in to the application.

## Actual Result

The terminated employee can still successfully log in and access the system.

## Impact

This creates a security and access control issue , Employee who is no loger part of orgination can access the resources. 

## Possible Root Cause

The login functionality may only validate credentials and may not be checking the employee status before granting access.
