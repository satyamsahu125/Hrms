## Title

Employee dashboard displays organization-wide statistics and administrative activities

## Severity
High

## Priority 
High

## Description

An employee user can view organization-level information on the dashboard, including employee counts, department counts, payroll statistics, quick stats, and recent activities performed by administrators.

## Steps to Reproduce

1. Launch the application.
2. Login using a valid employee account.
3. Observe the dashboard widgets and recent activity section.


## Expected Result

Employees should only see information related to their own profile

## Actual Result

Employee users can view restricted dashboard metrics and administrative activities.

## Impact

This exposes internal company information to users who do not require access to it.

## Possible Root Cause

Maybe Role Based Access Control not implemented .
maybe Server not returning the role based activity data.
